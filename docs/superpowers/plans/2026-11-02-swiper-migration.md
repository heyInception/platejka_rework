# Переход слайдеров на Swiper — план

> **Для реализации:** использовать `superpowers:executing-plans` и выполнять этапы последовательно, проверяя каждый тип слайдера до перехода к следующему.

**Цель:** заменить существующую обработку горизонтальных слайдеров на Swiper без изменения дизайна и пользовательского поведения на десктопе, планшете и iPhone.

**Архитектура:** локально подключённая и зафиксированная версия Swiper и один адаптер темы для повторяющихся каруселей. Секционные скрипты сохраняют только собственные функции: вкладки, видео, лайтбокс и анимации изображений. Стили размеров, промежутков и карточек остаются в CSS секций; Swiper отвечает за жесты, позицию, кнопки и состояние.

**Технологии:** WordPress/PHP, JavaScript, CSS, Swiper, Playwright.

**Точка отката:** локальная ветка `backup/pre-swiper-2026-11-02` от коммита `ee5855d`. Рабочие изменения в `cross-blocks.css`, `hero.css`, `infrastructure.css` и файлах `plugins/platejka-core/tools/` не относятся к миграции и должны остаться нетронутыми.

## Список слайдеров

| Секция | Экземпляров | Текущее поведение, которое нужно сохранить |
| --- | ---: | --- |
| `cases` | 1 | Карточки, горизонтальный свайп, стрелки и отключение стрелок на краях. |
| `serves` | 1 | Карточки, свайп, стрелки и адаптивная ширина. |
| `with-us` | 1 | Карточки с частично видимым следующим элементом, свайп. |
| `location` | 1 | Лента миниатюр, открытие фото по нажатию, лайтбокс, стрелки на десктопе. |
| `exhibitions` | 1 | Бесконечная галерея, свайп, стрелки на десктопе, выравнивание каждого фото. |
| `developing` | 1 | Слайды по годам, стрелки, кнопки годов и активный год. |
| `review` | 2 | Раздельные слайдеры видео и текста, вкладки, видео диалог, стрелки. |
| `review-main` | 2 | То же для основного варианта отзывов, включая действия на карточках. |
| `problems` | 1 | Слайдер карточек до 1024 px, настольная раскладка без слайдера. |
| `guarantees` | 1 | Горизонтальная лента до 1024 px, настольная раскладка без слайдера. |
| `shipments` | 1 | Горизонтальная лента до 1024 px, настольная раскладка без слайдера и анимация изображений. |
| `documents` | 1 | Горизонтальная лента документов до 1024 px и управление клавиатурой. |
| `about-hero` | 1 | Мобильная лента метрик с горизонтальной прокруткой и частично видимой следующей карточкой. |

Всего: **15 экземпляров в 13 типах секций**. Таблицы, строка категорий блога и прокручиваемый список годов остаются обычными областями прокрутки: они не являются отдельными каруселями; кнопки годов продолжают управлять `developing`.

## Ограничения

- Не менять ACF поля, тексты, изображения и HTML карточек без необходимости для Swiper.
- Сохранить текущие ширины карточек, промежутки, края секций, видимость кнопок и контрольные точки 576/1024 px.
- При отсутствии JavaScript карточки должны оставаться доступными через горизонтальную прокрутку там, где она есть сейчас.
- Не загружать Swiper с внешнего CDN: версия и файлы должны быть локальными и воспроизводимыми.
- Не включать посторонние рабочие изменения в коммиты миграции.

## Этапы реализации

### 1. Зафиксировать базовое поведение и зависимость

- [ ] Проверить актуальную версию Swiper по официальной документации и зафиксировать точную версию в `package.json`/`package-lock.json`.
- [ ] Сделать снимки и измерения ключевых секций на 390, 768, 1024 и 1440 px: ширина слайда, промежуток, видимая часть следующего слайда, положение стрелок.
- [ ] Добавить локальные JS/CSS файлы Swiper в тему и подключить их через WordPress с версией по времени изменения файла.
- [ ] Проверить, что библиотека загружается только на страницах с соответствующими секциями и не зависит от CDN.

### 2. Перевести общий горизонтальный слайдер

- [ ] Вынести инициализацию `data-horizontal-slider` в новый адаптер темы, используя существующие viewport/track/slide элементы как Swiper container/wrapper/slide.
- [ ] Перевести `cases`, `serves`, `with-us`, `location`, `developing`, `review`, `review-main`, `exhibitions` без изменения карточек.
- [ ] Сохранить события `horizontal-slider:change` и `horizontal-slider:refresh` либо обновить их потребителей одновременно: вкладки отзывов и активный год должны работать после открытия скрытой панели.
- [ ] Для `exhibitions` включить бесконечность только при достаточном числе слайдов; для остальных сохранить ограниченные края и состояние стрелок.
- [ ] Проверить открытие лайтбокса миниатюрой и отсутствие ложного клика после свайпа по интерактивной карточке.

### 3. Перевести секции с собственной логикой

- [ ] Перевести `problems`, `guarantees`, `shipments`, `documents` на Swiper только до 1024 px; создавать/уничтожать экземпляр при смене контрольной точки.
- [ ] Перевести мобильную ленту `about-hero__metrics`, сохранив размеры и внешний вид карточек.
- [ ] Удалить старые Pointer/Touch обработчики этих секций после проверки эквивалентного поведения Swiper.
- [ ] Оставить анимацию изображений shipments и функциональность карточек независимыми от слайдера.

### 4. Удалить старый механизм и проверить результат

- [ ] Удалить из загрузки `slider-touch-fallback.js` и отключить вызов старого инициализатора `horizontal-slider` в `common.js` после того, как все потребители работают через Swiper. В репозитории сейчас есть только собранный `common.js`, исходного модуля нет: изменить ровно точку вызова собственного модуля и не трогать код GSAP и других библиотек внутри пакета.
- [ ] Удалить конфликтующие `touch-action`, `scroll-snap` и transform правила только там, где Swiper ими управляет; оставить стили карточек.
- [ ] Добавить браузерные проверки свайпа, кнопок, границ, бесконечной галереи, переключения вкладок, годов, лайтбокса и мобильного/настольного переключения.
- [ ] Проверить размеры 390, 768, 1024, 1440 px и `prefers-reduced-motion`; отдельно выполнить проверку в WebKit/iPhone Safari, если доступен соответствующий движок или устройство.
- [ ] Сравнить скриншоты с исходными и проверить отсутствие ошибок JavaScript и горизонтального переполнения страницы.

## Критерий завершения

Все 15 экземпляров переключаются касанием и предусмотренными кнопками, адаптивный вид совпадает с текущим, вкладки/лайтбоксы/видео работают, а прежние обработчики не запускаются параллельно со Swiper. Откат выполняется восстановлением затронутых файлов из `backup/pre-swiper-2026-11-02` или обратным коммитом миграции, без сброса посторонних изменений.
